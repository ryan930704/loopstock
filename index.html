How it works

Serve, return, wash

Each wave uses clean cups first. The model rounds down the share returned from each wave and adds that batch after the chosen lag. Each wash batch clears up to the capacity you set. Shortfalls count as single-use fallback.

Plan for slower returns

The stress test drops returns by 10 percentage points, adds a wave of delay, and reduces wash capacity by 25%, rounded down. Both scenarios use the same demand and starting stock.

Measure it on event day

Log single-use cups issued per 100 drinks and any service interruptions. Compare similar events and record actual return and wash counts to refine the next plan.

The demo uses synthetic demand. The simulation assumes a fixed delay per batch and reports projected fallback under your inputs.
